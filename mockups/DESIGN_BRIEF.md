対象: サイト全面リニューアル（クリニカル・モダン）のホームページ候補3案。
この3案から めいき が1案を選定し、そのトークンを新サイト全体（globals.css）の正とする。

各案は**単一の自己完結HTMLファイル**。外部リクエスト禁止（CDN・Webフォント・画像URL不可。画像が要る場合はインラインSVG/データURI）。ローカルサーバーでも file:// でも開けること。

## 共通要件（全案必須）

### トーン
- クリニカル・モダン: 白ベース、シャープなブルー/インディゴ、余白広め、1pxの精密なボーダー、控えめなシャドウ、データ可視化が主役の SaaS ダッシュボード風。
- 現行サイト（暖色オフホワイト×ティール×茶）の面影を残さないこと。

### テーマ（ライト/ダーク）
- CSS変数トークンで両テーマ実装。構造: `:root`（ライト値）+ `[data-theme="dark"]` + `@media (prefers-color-scheme: dark){ :root:not([data-theme="light"]) }`。
- ヘッダーに動作するテーマトグル（`<html>` の `data-theme` を切替、選択を localStorage キー `mock.theme` に保存、初期値はOS追従）。
- ダークは自動反転ではなく専用に選んだ色（後述の検証を両モードで通す）。

### トークン命名契約（本実装の globals.css に持ち上げるので厳守）
```
--bg --surface --surface-2 --ink --ink-2 --muted --border
--primary --primary-strong --on-primary --accent
--success --warning --danger
--radius-sm --radius-md --radius-lg --radius-xl
--shadow-1 --shadow-2
--font-sans
```

### タイポグラフィ
- `--font-sans: "Inter", "Noto Sans JP", "Hiragino Sans", "Yu Gothic", sans-serif;`（モックはシステムフォントで描画されてよい。本実装で next/font によるセルフホストに置換する）。
- 数値はすべて `font-variant-numeric: tabular-nums`。
- 見出しは明確なタイプスケール（例 12/14/16/20/28/40）を定義して一貫使用。

### 共通シェル
- ヘッダー: 左にロゴ（テキスト「臨床学術WG」+ 簡潔なインラインSVGマーク。新ロゴは暫定でよいが旧「Learning Loop」マークは使わない）、ナビ: ホーム / アーカイブ / コース / カレンダー / ダッシュボード、右端にテーマトグル。モバイルではハンバーガー（開閉動作必須）。
- フッター: About / 利用規約 / プライバシーポリシー / 問い合わせ、運営者表記「臨床学術ワーキンググループ」。

2. **今日の復習キュー**: 3件（復習エンジンの出力想定）
3. **学習ステータス**: 連続学習 12日 / バッジ 5個 / 完了レッスン 14 / クイズ平均正答 82%
4. **コース進捗**: 6コース（下記実データ）
5. **最新アーカイブ**: 3件
6. **学会カレンダー導線**: 直近の学会1件を添える
7. クイズへの導線（「確認クイズを解く」等）

### データ可視化規約（dataviz スキル準拠、全案必須）
- スタット数値・ラベル・凡例の**文字色は必ずインク系トークン**（`--ink`/`--muted`）。系列色を文字に使わない。
- 進捗バー/リングは細いマーク・角丸端・ベースライン基準。積み上げ・隣接フィルの間は 2px のサーフェス色ギャップ。
- 系列が2つ以上あるチャートには凡例必須。1系列なら凡例なし（タイトルが名前を兼ねる）。全点ラベルは禁止、直接ラベルは選択的に。
- 2軸チャート禁止。レインボー禁止。順序データは単一色相の明度勾配。
- ステータス色（success/warning/danger）は状態専用。系列色に流用しない。色だけで状態を伝えない（アイコン/ラベル併記）。
- カテゴリ色（テーマ6種のチップ等）を使う場合は固定順で割り当て、フィルタで塗り替えない。
- 使用したカテゴリ/アクセントパレットは検証スクリプトで両モード合格させること:
  `node "/private/tmp/claude-501/bundled-skills/2.1.209/fbd296b050e303d941aac8b39ccef8fd/dataviz/scripts/validate_palette.js" "<hex,hex,…>" --mode light`（`--mode dark` も。surface はモックの `--surface` 値を渡す）。

### 品質基準（検収条件）
- 375px 幅で横スクロールなし。1280px でデスクトップレイアウト。
- WCAG AA コントラスト（本文 4.5:1、大見出し 3:1）。`:focus-visible` スタイルあり。
- テーマトグルが両方向に動作し、リロードで選択が保持される。
- コンソールエラーなし。外部リクエスト 0 件。
- HTML/CSS/JS は2スペースインデント、プレーンJS（AGENTS.md 規約）。

## 各案の差別化指針

### A: ダッシュボード型（home-a.html）
- 上段にスタットタイル4枚の行、その下を12カラムグリッドで「続きから+復習キュー」「コース進捗（進捗リング）」「最新アーカイブ」「学会」を密度高く配置。
- 週間学習アクティビティのミニ棒グラフ（7日分、1系列、ダミー値可）を含める。
- 情報の一覧性・「管理画面感」を最大化する案。

### B: 「今日の1本」フォーカス型（home-b.html）
- ファーストビューは大型ヒーロー1枚 =「今日はこれを復習」（続きから or 復習キュー先頭）。大きなタイポグラフィ、行動ボタン1つ。
- スタットは薄いストリップ、他ブロックはヒーロー下に1カラムで簡潔に。
- 迷わせない・认知負荷最小の案。

### C: タイムライン/ライブラリ型（home-c.html）
- アーカイブを月ごとの縦タイムラインで時系列表示（テーマ別カラーチップ付き）。
- デスクトップでは右側にスティッキーな「学習レール」（続きから・スタット・復習キュー）。
- 蓄積が見える・アーカイブの資料館的性格を強調する案。
