# 学会年会一覧の自動更新メモ

## 対象ファイル
- 公開データ: `public/data/annual-meetings-2026.js`
- 表示ページ: `public/annual-meetings-2026.html`, `app/annual-meetings-2026/page.tsx`
- 更新スクリプト: `scripts/refresh_annual_meeting_windows.js`

## 2週間ごとの確認内容
1. `public/data/annual-meetings-2026.js` の各 `primaryUrl` と `sources[].url` を公式情報として確認する。
2. 演題募集、採択、参加登録、開催概要、会場、テーマ、会長/年会長、重要なお知らせに変更があれば反映する。
3. 次回年会の案内が公式に出ている場合は、新しい開催回を別レコードとして追加する。旧回は削除せず、会期終了後に `status: "past"` として残す。
4. 日付は `YYYY-MM-DD` で統一し、確実に確認できない日程は推測で埋めず `note` に「公式ページを確認してください」などの保留情報を書く。
5. `verifiedAt` は確認実施日に更新する。

## 自動処理でできること
- `npm run meetings:refresh` は、対応済みの学会について演題募集・参加登録期間を公式ページから再取得する。
- 確認日時点で `endDate` を過ぎた学会は、同スクリプトが `status: "past"` と `archivedAt` を付ける。
- 一覧画面では `status: "past"` の学会を「終了した学会」として分けて表示する。

## 手作業確認が必要なこと
- 次年度/次回年会の初出確認
- URL構成が変わった公式サイトの追跡
- PDFや画像だけで告知されている募集期間の読み取り
- 公式情報が複数ページで食い違う場合の判断

## 追加で決めたいこと
- 監視対象にする学会の増減
- 年度が変わったときに `annual-meetings-2027` のような年度別ページを作るか、単一ページを最新年度へ置き換えるか
- 自動ジョブの変更をそのままコミット/PR化するか、差分報告だけにするか
