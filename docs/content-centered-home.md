# 教材を選びやすくするホーム・一覧改修

2026-09-07。学習記録中心だったホームを、教材の内容から学び始められる構成に変更。

## 表示の方針

- ホーム上部におすすめ、学習履歴がある場合は再開・復習の教材を掲載。既存の復習候補ロジックと端末内の進捗を使用。
- 実際の録画サムネイル、既存の学習ポイント、講師・開催日・クイズ数を表示。新着の録画、分野別の検索、コースへ進める。
- 進捗と学会情報は下部に配置。詳細な学習記録はダッシュボードで確認する。
- 録画のない教材には画像枠や「視聴」ボタンを作らず、要点から学ぶリンクを表示。
- 学習ポイントがない教材は既存の概要を使用。未記載の所要時間は非表示。教材の教育内容や生成データは変更していない。
- 一覧はスライド内の文字を保護するcontain表示。ホームは動画画像の上下の余白を切り取る16:9表示。

## サムネイルの運用

`content/archive-thumbnails.json` に教材ID、ローカル画像、元URL、動画IDを記録。
8枚の元画像を `public/images/archives/` へ配置。閲覧時にYouTubeの画像サーバーへ接続しない。
動画IDが現在の録画リンクと一致する場合だけ表示するため、リンク変更時に別動画のサムネイルを流用しない。

```sh
npm run thumbnails:refresh:dry # 対象確認。通信・書き込みなし
npm run thumbnails:refresh     # 元画像を取得してマニフェスト更新
```

取得時はJPEG形式とサイズを検証し、120×90の未提供画像を除外する。
取得失敗時は同じ動画IDの有効な既存画像を保持し、終了コード1で失敗を通知。

### ページ内動画再生（2026-09-08）

詳細ページはサムネイルの再生ボタンから、同じ場所のYouTubeプレーヤーへ切り替わる。
YouTube通信はクリック後に開始し、プライバシー強化モードの埋め込みURLを使用。
スマホのインライン再生と全画面表示に対応し、「YouTubeで見る」リンクを常設。
埋め込み許可・ログイン制限・ブラウザの自動再生制限はYouTube側の設定にも依存する。
自動テストでは外部iframeの応答をモックし、クリック前の非表示・切替先URL・同一ページの維持を検証する。
参考: https://developers.google.com/youtube/player_parameters および https://support.google.com/youtube/answer/171780?hl=ja （2026-09-08確認）。

ページ内再生の最終検証: 型チェック・本番ビルド・Node22件・PC/スマホ18件通過。
Codex内ブラウザでも「病院薬剤師の仕事」の実動画がページ内で再生され、映像・字幕・再生コントロールを確認。一時停止してプレビューを残した。
他7動画のYouTube側の再生許可は個別には確認していない。
