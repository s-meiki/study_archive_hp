# 確認クイズ レビューシート

勉強会アーカイブの確認クイズ（`content/quizzes/*.json`）の内容を薬剤師がレビューするための一覧です。

> **記録（2026-07-08）**: 全24本・78問は 2026-07-07 にめいきが一括承認済み（`docs/publish-readiness-plan.md` WP-A 参照）。個別の判定欄は記入せず運用を終了した。全ファイル `reviewStatus: "reviewed"` 反映済み。以後の新設問レビューは設問単位で行う（複数選択分は `docs/quiz-review-sheet-multi.md`）。

## 使い方

1. 各設問の内容（設問文・選択肢・正答・解説）を確認する。
2. 各設問の「判定」欄に、問題なければ `OK`、修正が必要なら `要修正: <修正内容のメモ>` を記入する。
3. クイズ1本（1ファイル）の全設問が `OK` になったら、該当する `content/quizzes/<archiveId>.json` の
   `reviewStatus` を `"draft"` から `"reviewed"` に変更する。
4. `npm run quiz:build` を実行して `public/data/quiz-bank.js` を再生成すると、
   `reviewStatus: "reviewed"` のクイズのみが公開データに収録される。

※ このシート自体はレビュー記録用であり、`content/quizzes/*.json` を直接書き換えるものではありません。
