## 参考: 代行検証 (2026-07-08 実施済み)

本番前の先行検証として、バンドルのみを参照させた別モデルで同等の制作テストを実施済み。結果と guidelines への反映は下記「代行検証の結果」節を参照。

### 代行検証の結果

- 方法: バンドル(`design-system/`)のみ参照可・サイトCSS参照禁止の条件で、別モデルに (a)第66回告知スライド1枚 (b)開催前の注目カード(直接の見本なし・流用構成) を制作させ、実描画をレビュー。
- **視覚的忠実度: 合格。** 2点ともトークン外の色・角丸・影の発明ゼロ。見本と並べて違和感なし。テンプレに無い部品(b)も既存見本の組み合わせで正しく構成できた。
- **検出された不足 → guidelines.md に反映済み (2026-07-08)**:
  1. 開催前告知の型が未定義(テーマチップ併置・再生UIなし・受付状況チップ・免責不要・演者表記) → §7に「開催前の告知物の型」を新設
  2. 固定サイズ媒体でのタイポ規定(clamp不適用、見本の固定値が正) → §4に追記
  3. eyebrowサイズの実態(スライド0.82rem)と表の乖離 → §4のレンジを媒体別に修正
  4. カード枠線(白縁 vs --line)の使い分け基準が無い → §5に基準を明文化
  5. 「注目の回/今月の注目」の使い分け、サムネ地グラデ2種の使い分け → §6に追記
- 本番テスト1の合格見込みは高いが、**テスト3(禁止事項への耐性)は本番でしか検証できない**ため必ず実施すること。
