# 勉強会アーカイブ紹介LP 設計図

## 0. 今回の設計方針

このLPは、`臨床学術ワーキンググループ` を初めて知る新規参加候補者に向けて、サイトの役割と勉強会の雰囲気を伝える紹介ページとして設計する。

単なるアーカイブ機能の説明ではなく、次の3つの行動につなげる。

1. 「まずページを見てみたい」と思ってもらう
2. アーカイブ閲覧をきっかけに「勉強会に参加してみたい」と思ってもらう
3. オープンチャットに参加し、勉強会URL・日程・最新情報を受け取ってもらう

決定事項:

- 主対象: 新規参加候補の薬剤師・医療従事者
- 公開範囲: 完全公開
- LPの役割: サイト紹介 + アーカイブ閲覧導線 + オープンチャット参加導線
- 主CTA: `アーカイブを見る`
- 副CTA: `オープンチャットに参加する`
- オープンチャット名: `臨床学術WG_SET.Ph`
- オープンチャットURL: `https://line.me/ti/g2/SPaVzas9vc10ud3xYYKBoNOpnkXyMz40DHDFOg?utm_source=invitation&utm_medium=link_copy&utm_campaign=default`
- QRコード画像: `public/images/openchat-qr.png`
- 参加導線: オープンチャットURLとQRコードをセットで掲載する
- 参加条件: 特になし
- 開催形式: 最低月2回、ハイブリッド開催
- 共有内容: 録画あり、資料共有あり
- 直近予定: `2026-07-10 17:30 ワクチン完全攻略` と `2026-07-24 17:30 薬物動態 ~基礎編~` を初期表示する
- 直近予定の管理方針: 初期は `app/about/page.tsx` 内の `upcomingMeetings` 配列で簡単に管理し、将来的に管理画面編集へ拡張する
- LP運用方針: LP本体は継続利用し、時期ごとに `直近の勉強会予定` だけ更新する
- 管理画面方針: 可能なら管理画面から直近予定を編集できるようにする。ただし初回実装が重くなる場合は、LP公開後の次フェーズに回す
- 参加前注意事項: 一般的なオープンチャット利用ルールを短く掲載する
- トーン: 誠実、落ち着き、学びの空気が伝わる、医療者向けに信頼できる

## 1. LPの目的

### 主目的

新規参加候補者に対して、このサイトが「薬剤師・医療従事者向けの勉強会アーカイブ」であり、過去の学びを見ながら勉強会の雰囲気を知れる場所だと伝える。

### 行動目標

- アーカイブ一覧ページを開く
- 興味のあるテーマの勉強会を1つ見る
- 直近の勉強会予定を確認する
- オープンチャットURLまたはQRコードから参加する
- オープンチャットで勉強会URL・日程・最新情報を受け取る

### 副目的

- 臨床学術ワーキンググループの活動内容を伝える
- 継続的に学び合う場であることを伝える
- 初参加前の心理的ハードルを下げる
- 医療系コンテンツとして、教育目的・匿名化・問い合わせ導線を明示する

## 2. 想定ユーザー

### メインユーザー

勉強会や臨床学習コミュニティに関心はあるが、まだ参加したことがない薬剤師・医療従事者。

### ユーザーの状態

- どんな勉強会なのか、参加前に雰囲気を知りたい
- 自分の臨床や業務に役立つ内容か確認したい
- 参加してもついていけるか少し不安がある
- 忙しいので、まずは過去の回を見て判断したい
- 最新の勉強会情報を受け取る場所がほしい
- スマホでQRコードを読み取る、またはリンクからすぐ参加したい

### LPを見た直後に感じてほしいこと

- 「こういう勉強会なら一度見てみたい」
- 「過去回を見れば雰囲気がわかりそう」
- 「テーマが整理されていて、自分に関係ある回から入れそう」
- 「オープンチャットに入れば最新情報を受け取れそう」
- 「参加条件が厳しくなさそうで、入りやすい」

## 3. 価値提案

### コアメッセージ

### サブメッセージ

臨床学術ワーキンググループは、薬剤師・医療従事者が臨床、研究、基礎レクチャー、AI活用などを継続的に学び合う勉強会です。最低月2回のハイブリッド開催で、録画や資料も共有しています。過去回のアーカイブや直近予定を見て雰囲気を確認し、最新情報はオープンチャットで受け取れます。

理由:

### 見出し候補

- 学び合う場の雰囲気を、まずはアーカイブから。

- 薬剤師・医療従事者のための、勉強会アーカイブ。

### CTA候補

- アーカイブを見る
- オープンチャットに参加する
- QRコードから参加する
- 最新の勉強会情報を受け取る
- 気になるテーマから見る
- 勉強会について問い合わせる

CTA優先順位:

1. `アーカイブを見る`
2. `オープンチャットに参加する`
3. `気になるテーマから見る`
4. `勉強会について問い合わせる`

## 5. ページ構成

### 1. ファーストビュー

目的: 何のサイトで、誰に向けた勉強会なのかを3秒で伝える。

掲載要素:

- ラベル: `薬剤師・医療従事者向け勉強会`
- H1: `学び合う場の雰囲気を、まずはアーカイブから。`
- リード文: 勉強会の概要、開催頻度、アーカイブを見られることを説明
- CTA: `アーカイブを見る`
- サブCTA: `オープンチャットに参加する`
- 補足: `最低月2回のハイブリッド開催。録画・資料共有あり。最新情報はオープンチャットで受け取れます`
- QRコード: ファーストビューまたは参加方法セクションに、オープンチャット参加用QRを掲載する

ファーストビューで避けること:

- 機能説明だけで終わる
- 「参加しないと損」のような煽り
- 実績を大きく見せすぎる
- 医療成果を連想させる断定

### 2. このサイトについて

目的: 新規参加者に「これは何の場所か」を説明する。

見出し候補:

`このサイトは、勉強会の学びを見返せる公開アーカイブです。`

掲載内容:

- 臨床学術ワーキンググループの勉強会を整理している
- 過去回の録画・資料・要点を確認できる
- 初めての人は、参加前に雰囲気を知る入口として使える
- 既存参加者は、復習や資料確認に使える
- 最新の勉強会情報はオープンチャットで受け取れる

### 3. 勉強会で扱うテーマ

目的: 自分に関係がありそうだと思ってもらう。

テーマ例:

- 循環器
- 脳神経
- 感染症
- 基礎レクチャー
- 研究・認定
- AI活用

見せ方:

- テーマごとに短い説明を添える
- 各テーマからアーカイブ一覧へ遷移できる想定にする
- 新規参加者が「ここからなら見られそう」と感じる入口を作る

### 4. アーカイブでできること

目的: 実際の使い方を具体化する。

機能ブロック:

1. テーマから探せる
   - 関心分野から過去回を確認できる
2. 録画や資料の有無がわかる
   - 録画、スライド、要点メモ、参考文献を一覧で確認できる
3. 詳細ページで内容を確認できる
   - 概要、学習ポイント、関連アーカイブを確認できる
4. 学会年会一覧も確認できる
   - 勉強会だけでなく、学会参加の計画にもつなげられる

### 5. 初めての方へ

目的: 参加前の不安を下げる。

見出し候補:

`参加前に、まず1本見てみてください。`

伝える内容:

- いきなり参加しなくても、過去回から雰囲気を確認できる
- 気になるテーマだけ見ればよい
- 基礎レクチャーから入ることもできる
- 参加条件は特になく、まずオープンチャットで情報を受け取れる
- オープンチャットに入れば、勉強会の日程や参加URLを確認できる

### 6. 参加方法と最新情報

目的: 参加への具体的な一歩を明確にする。

掲載内容:

- 参加条件は特になし
- まずはオープンチャットに参加する
- オープンチャットURLとQRコードを掲載する
- オープンチャットで勉強会の日程、参加URL、最新情報を共有する
- 勉強会は最低月2回、ハイブリッドで開催する
- 録画と資料共有があるため、当日参加できない場合も後から確認できる
- 参加前の注意事項として、一般的なオープンチャット利用ルールを短く掲載する

CTA:

- `オープンチャットに参加する`
- `最新の勉強会情報を受け取る`

QRコード表示:

- QRコード画像は `public/images/openchat-qr.png` で管理する
- URLが変わった場合は、QRコード画像も差し替える
- QRコードの近くに確認用のURLテキストまたはリンクボタンを併記する
- スマホ閲覧者向けにはボタン、PC閲覧者向けにはQRコードを主導線として機能させる
- QRコードには `オープンチャット参加用QRコード` の代替テキストを設定する

注意事項のたたき台:

- 医療情報・個人情報の取り扱いに注意してください
- 症例や患者情報を投稿する場合は、個人が特定されない形にしてください
- 誹謗中傷、営業・勧誘目的の投稿、無断転載は控えてください
- 勉強会情報の共有を目的とした場として、節度ある利用をお願いします
- 参加URLや資料の扱いは、運営からの案内に従ってください

### 7. 直近の勉強会予定

目的: LP上で活動が継続していることを伝え、参加の具体性を高める。

掲載内容:

- 直近2〜3件の勉強会予定
- 開催日
- 時間
- テーマ
- 開催形式
- 録画予定の有無
- 資料共有予定の有無
- 詳細や参加URLはオープンチャットで案内する旨

表示方針:

- LP本体の説明、CTA、オープンチャット導線は基本的に固定する
- その時々で変わるのは `直近の勉強会予定` のみとする
- LPに直近予定の表示枠を置く
- 詳細な参加URLはオープンチャットへ集約する
- 予定変更に備えて、日程・テーマ・形式を差し替えやすいデータとして管理する
- 直近予定が未入力の場合は、`最新予定はオープンチャットでご確認ください` と表示する

データ項目案:

```yaml
upcomingMeetings:
  - id: meeting-20260710
    date: 2026-07-10
    time: "17:30"
    title: ワクチン完全攻略
    theme: ワクチン
    format: ハイブリッド
    recordingPlanned: true
    materialsPlanned: true
    note: 参加URLと詳細はオープンチャットで共有
  - id: meeting-20260724
    date: 2026-07-24
    time: "17:30"
    title: 薬物動態 ~基礎編~
    theme: 薬物動態
    format: ハイブリッド
    recordingPlanned: true
    materialsPlanned: true
    note: 参加URLと詳細はオープンチャットで共有
```

更新運用:

- 直近予定はアーカイブ本体とは別データで管理する
- 更新担当者が日程・テーマだけ差し替えられる構造にする
- 日付が過ぎた予定は非表示、またはアーカイブ側へ移す
- 予定の詳細やURLは、LP上に細かく出しすぎずオープンチャットに誘導する

実装候補:

- 小規模運用なら `app/about/page.tsx` 内の配列で管理する
- 更新頻度が上がるなら `public/data/lp-content.js` のようにLP用データへ分離する
- 管理画面から更新したい場合は、既存の `admin/` 運用に `直近予定` 項目を追加する
- 管理画面対応を入れる場合は、既存のアーカイブ編集とは分けて `LP設定` または `直近予定` セクションとして追加する

### 8. 勉強会に参加すると得られること

目的: アーカイブ閲覧から参加意欲へつなげる。

掲載内容:

- 臨床テーマを継続的に学べる
- 他の薬剤師・医療従事者の視点に触れられる
- 研究・認定・学会など、キャリアに関わるテーマにも触れられる
- AI活用など、新しい実務テーマも扱える
- 最低月2回の開催があるため、学びを継続しやすい
- ハイブリッド開催なので、状況に合わせて参加しやすい
- 録画と資料共有があるため、参加後も見返しやすい

注意:

- 「参加すれば必ず成長できる」とは書かない
- 成果保証ではなく、学習環境・機会として表現する

### 9. 信頼性・安全性

目的: 完全公開にするため、医療系コンテンツとしての前提を明示する。

掲載要素:

- 教育用コンテンツであり、個別診療の代替ではない
- 症例情報は匿名化前提で扱う
- 著作権・公開許可・外部リンクを確認する運用
- 問い合わせ・削除依頼の窓口
- 利用規約・プライバシーポリシーへの導線
- オープンチャット利用時の一般的な注意事項

文言候補:

本アーカイブは教育目的の学習資料です。個別診療の判断を代替するものではありません。症例や資料を扱う場合は、匿名化・公開許可・権利確認を前提として運用します。

### 10. 最終CTA

目的: ページを読んだ人に次の行動を促す。

見出し候補:

`気になるテーマから、まず1本見てみる。`

CTA:

- メイン: `アーカイブを見る`
- サブ: `オープンチャットに参加する`

## 8. デザイン方針

### トーン

- 新規参加者が入りやすい
- 医療者向けの信頼感がある
- 静かで整理された印象
- 学習意欲を支えるが、煽らない
- 「参加してみたい」と思える温度感はあるが、営業色は抑える

### 色

既存ページに合わせる。

- ベース: 白、淡いグレー
- メイン: 深い青緑系
- 補助: 落ち着いた黄土・グレー
- 注意: 赤はエラー・重要警告に限定

### UI

- ファーストビューは説明量を絞り、CTAを明確にする
- テーマ一覧は入口として目立たせる
- アーカイブ機能は「便利機能」ではなく「参加前に雰囲気を知れる手段」として見せる
- オープンチャット参加CTAは、アーカイブ閲覧CTAと並べる
- QRコードは参加方法セクションで見やすく配置する
- 直近予定はカード形式で2〜3件表示する
- `月2回以上` `ハイブリッド` `録画あり` `資料共有あり` は小さな信頼ラベルとして置く
- 完全公開なので、運営・教育目的・問い合わせ導線を見つけやすくする
- スマホではファーストビュー直下に `アーカイブを見る` と `オープンチャットに参加する` を置く

## 11. 医療・法務・運用上の注意

完全公開のLPなので、以下は必ず扱う。

- 教育目的であり、個別診療の代替ではない
- 症例情報は匿名化前提
- 削除依頼・問い合わせ窓口
- 外部サービスへのリンクがある場合の注意
- 利用規約・プライバシーポリシー
- 一般向け医療広告のように見えない表現設計
- オープンチャット参加前の注意事項

避ける表現:

- 「必ず臨床力が上がる」
- 「これだけ見れば十分」
- 「最短で専門家になれる」
- 「参加すればキャリアが変わる」
- 特定治療の優位性を断定する表現
- 患者アウトカム改善を保証する表現

## 12. 実装時のページ案

### URL候補

- `/about`
- `/join`
- `/study-archive`
- `/lp`

おすすめは `/about`。

理由:

- 完全公開の紹介ページとして自然
- 新規参加者が「このサイトは何か」を理解しやすい
- 既存の `/` がアーカイブ一覧なので、役割を分けやすい
- 将来、参加案内を強める場合は `/join` を別ページとして追加できる

### 実装優先度

MVP:

- ファーストビュー
- このサイトについて
- 扱うテーマ
- アーカイブでできること
- 初めての方へ
- 参加方法と最新情報
- 直近の勉強会予定
- 勉強会に参加すると得られること
- 信頼性・注意書き
- 最終CTA

次フェーズ:

- オープンチャットURLの反映
- QRコード画像の配置
- 代表的な過去回の表示
- 初参加者向けおすすめ回
- 直近開催予定の管理画面対応
- よくある質問

### 更新しやすくする設計

LP本体は継続利用し、直近予定だけを差し替える前提にする。直近予定はLP本文に直接埋め込まず、できればデータとして分離する。

初期実装:

- `app/about/page.tsx` 内に `upcomingMeetings` 配列を置く
- 件数が少ないうちはこれで十分
- 変更時は配列だけ差し替える
- 今回はこの簡単管理方針で進める
- LP公開を優先する場合は、まずこの形で公開する

将来実装:

- `public/data/lp-content.js` にLP用データを分離する
- `admin/` から直近予定を編集できるようにする
- 日付が過ぎた予定は自動で非表示にする
- 管理画面編集は、LP公開後に更新頻度を見て追加する
- 管理画面で編集する場合、保存先は `public/data/lp-content.js` を想定すると既存の `public/data/site-content.js` と役割を分けやすい

QRコード管理:

- QR画像は `public/images/openchat-qr.png` の固定パスで管理する
- URLが変わったら同じファイル名で画像を差し替える
- 画像差し替えだけでLP側の実装を変えなくてよい構造にする
