# 復習中心ホーム刷新 — 実装仕様

作成: 2026-07-13

## 結論

既存参加者がトップページを開いてすぐ復習へ戻れるよう、3案を次の1画面へ統合する。

1. **今日の復習**: 直近の学習状態から、次に取り組む1件を主CTAとして提示する。
2. **復習インボックス**: 未修了・クイズ再確認・最近見た回を優先順で並べる。
3. **分野マップ**: 6コースと24レッスンを、現在地が分かる学習経路として表示する。

文字起こしは追加しない。進捗は既存の `cawg.learning.progress.v1` を使い、この端末のブラウザにのみ保存する。

## 表示ルール

- 「今日の復習」は、実データに存在するアーカイブと公開済みクイズだけを使う。
- 優先順位は `未修了の最終訪問 > 視聴済み未修了 > クイズ得点が100%未満 > 未着手の次レッスン`。
- 所要時間や復習期限は現スキーマにないため表示しない。代わりに実数の「確認クイズ N問」を表示する。
- 初回利用時は架空の進捗を作らず、最初のコース／アーカイブを選ぶ導線へ切り替える。
- 存在しない archiveId や壊れたローカル保存は無視し、安全な初回状態へ戻す。
- コースから開くリンクには `courseId` を付与し、最終訪問にもコース文脈を保存する。

## レスポンシブ順序

デスクトップは `今日の復習 → 復習インボックス（2ペイン）→ 分野マップ → アーカイブ検索`。
モバイルは `今日の復習 → 続き → 復習候補 → 分野マップ → 検索` の1列とし、主CTAを最初の画面内に置く。

## ブランド更新

- マーク: 「学びの循環」。復習ループのC、学習経路のA、開いた本を一体化する。
- 色: 現行の `#365a5c` と `#97724b` を維持する。
- OGP候補コピー: 「前回の学びを、次の現場へ。」
- OGP補足: 「続きから再開できる、薬剤師向け勉強会アーカイブ」
- OGPチップ: 「続きから再開」「確認クイズ」「テーマ別コース」

`design-system-update` の承認境界に従い、OGP候補を確認後に承認された「前回の学びを、次の一歩へ。」案を `public/images/ogp.png` へ反映した。デザインシステム側の候補も同一画像に同期している。

## 将来のDiscordログイン

- 現在の進捗JSONをそのままサーバー保存できる形に保ち、端末内データをゲスト用キャッシュとして扱う。
- Discord OAuth導入時は、初回ログインで端末内進捗をアカウントへ引き継ぐ確認を出す。
- 複数端末の競合は、レッスンごとの `watchedAt` / `completedAt` とクイズのベストスコアを使ってマージする。
- ログインしなくても現在どおり学習でき、ログインは同期・機種変更のための任意機能にする。

## 完了条件

- ホームの主CTAから詳細へ進み、視聴・クイズ・修了状態がホームへ反映される。
- コース経由の訪問で `courseId` が保持され、ホームと詳細からコースへ戻れる。
- 空進捗・既存進捗・不正JSONでクラッシュしない。
- 1440px / 1024px / 390px で横スクロール、重なり、操作不能がない。
- TypeScript、learning/quiz dry-run、Next build が成功する。
- ブラウザで主要導線・コンソール・モバイル表示を確認する。
- `design-qa.md` が `final result: passed` になる。
