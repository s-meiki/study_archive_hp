## エグゼクティブサマリー（重要指摘）

1. **【最重要・修正推奨】optional の欠落 — foundations「poly pharmacy」が同内容2回とも本編扱い。** 修了率の分母を同一内容で二重計上している。片方を `optional: true` にすべき（neurology の再演処理と同じ考え方）。
2. **【要確認】research-career「帰還報告会(医療薬学会)」×2 も再演の可能性が高い。** 開催3週間差・要約完全一致。同内容の再演なら片方を optional に。別開催の報告なら現状維持（主催者に確認）。
3. **【順序】基礎→応用の逆転が research-career で発生。** 開催日昇順ルールの副作用で「accept論文 報告会（各論）」が「臨床研究とは（概論）」より前に来ている。学習動線上は概論が先頭であるべき。READMEの日付ルールとの整合は要ポリシー判断。
4. **【粒度】薄い2コース（cardiology／infectious）は「現状維持＋将来拡充」が妥当。** 統合は不適切。内部に「総説→各論」「虚血→不整脈」の勾配が既に成立しており、無関係回での水増しは質を下げる。
5. **【タイトル】学習者（若手薬剤師）が内容を想像できないラベルが複数。** 「基礎から固めていこう」「帰還報告会」「poly pharmacyについて」「臨床研究ってなに?…（長い疑問文）」。`labelOverride` で表示名を補うのが有効（本文タイトルは温存）。
