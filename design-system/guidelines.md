# 臨床学術ワーキンググループ — ブランドガイドライン (AI向け仕様書)

このドキュメントは Claude Design がこのブランドの成果物 (スライド・LP・ワンページャー・SNS画像・資料) を作るときの唯一の判断基準。迷ったらここに従う。実物見本は `foundations/` `components/` `templates/` のプレビューHTMLにある。**新しい見た目を発明する前に、必ず見本から一番近いものを探して流用する。**

## 1. ブランドの正体

- 正式名称: **臨床学術ワーキンググループ** (英語添え字: Clinical Academic Working Group)
- 何者か: 薬剤師・医療従事者が臨床/研究/基礎レクチャー/AI活用を学び合う勉強会。月2回以上、ハイブリッド開催、録画・資料を公開アーカイブとして整理。
- 代表コピー: 「**必要な勉強会に、すぐ届く。**」
- テーマ分類 (固定語彙): 循環器 / 脳神経 / 感染症 / 基礎レクチャー / 研究・認定 / AI活用

## 2. 声とトーン

- 落ち着いた・誠実・実務的。医療専門職に向けた文体。
- 機能価値を短文で言い切る:「すぐ届く」「見返せる」「短時間でたどり着ける」。
- 見出しは体言止めか短い言い切り。感嘆符・絵文字・煽りは使わない。
- **禁止**: 誇大表現(「誰でもプロ級」「絶対」「No.1」)、診療判断の断定(「〜すれば治る」)、効能の保証。
- 症例・患者情報は必ず匿名化した架空例のみ。個人名は出さない(運営者名も資料内では「事務局」「運営」と表記)。
- 教育コンテンツには免責を添える: 「本アーカイブは個別診療の判断を代替するものではありません。」

## 3. 色

トークンの正: `tokens/tokens.css`。実物見本: `foundations/colors.html`。

| 役割 | 値 | 使い方 |
|---|---|---|
| 背景 `--bg` | `#f6f3ec` | ページ・スライドの地。真っ白は使わない |
| 面 `--surface` | `#fffdf9` | カード・パネル。背景より一段明るい |
| 沈めた面 `--surface-muted` | `#faf6ef` | 入力欄・引用・サブ面 |
| 文字 `--ink` | `#24343b` | 見出し・本文 |
| 補助文字 `--muted` | `#6b7b82` | キャプション・メタ情報 |
| 主色 `--primary` | `#365a5c` | 強調・ボタン・アクティブ状態。塗り面の文字は `#ffffff` |
| 主色淡 `--primary-soft` | `#e5efee` | バッジ・ラベルの背景 |
| アクセント `--accent` | `#97724b` | 副次的な強調・リンクhover。多用しない |
| 罫線 `--line` | `rgba(36,52,59,0.1)` | ボーダーは常にこの薄さ |

- 配分の目安: 背景・面が9割、primary は1割弱、accent は差し色のみ。
- セマンティック: 成功/登録=`#2d6c45`系、注意/保留=茶系(`#8c4f1f`)、エラー/不正解=`#8a3f30`系。
- **禁止**: 純黒 `#000`・純白背景、彩度の高い赤・青・黄、グラデーションの多用(グラデは原則使わない)。
- ロゴマークは Learning Loop。A・開いた本・時計回りの矢印で、復習から実践へつながる学びを表す。サイト実体は `public/images/brand-mark.svg`。形・色・比率を改変しない。

## 4. タイポグラフィ

フォント: `"Hiragino Sans", "Yu Gothic", sans-serif` (システムフォントのみ。Webフォント禁止)。実物見本: `foundations/typography.html`。

| 役割 | サイズ | 行間 | 字間 | 太さ |
|---|---|---|---|---|
| 大見出し (h1/表紙) | clamp(2.2rem, 4.4vw, 3.9rem) | 1.04 | -0.05em | 通常〜600 |
| セクション見出し (h2) | 1.64rem | 1.2 | -0.03em | 700 |
| カード見出し (h3) | 1.32rem | 1.28 | -0.03em | 700 |
| 本文 | 0.95〜1rem | 1.7〜1.85 | 0 | 400 |
| リード文 | 1rem | 1.72 | 0 | 400 |
| ラベル/eyebrow | 0.72〜0.78rem (大判スライドのみ0.82remまで可) | 1 | **+0.08em・大文字** | 700 |
| 統計数値 | 1.9rem〜 | 1.1 | -0.03em | 800 |

- 原則: **見出しは締める(負の字間)、ラベルは開く(正の字間+uppercase)**。
- 日本語見出しの改行位置は意味で切る。1行が長くなりすぎたら `clamp` 内で自然に折り返す。
- **媒体による使い分け**: 上表の `clamp()` はWebページ用。スライド・SNS画像・A4など**固定サイズの媒体では clamp/vw を使わず、各テンプレ見本の固定値に従う** (例: スライドh1=3.3rem)。見本と本表が食い違うときは、その媒体の見本が正。

## 5. 形・余白・影

- 角丸: パネル 28px / カード 20px / 内部要素 16px / ボタン・チップ・入力欄は完全ピル (999px)。
- 影: `0 12px 30px rgba(36,52,59,0.07)` のみ。濃い影・多重影は使わない。
- 余白: 8px基調 (12/16/24/28…)。カードpadding 18〜22px、パネルpadding 24〜36px。
- カードのborderの使い分け: **surface面の基底カード(.panel系)と写真の上に重ねるカードは白縁 `rgba(255,255,255,0.92)`、沈めた面・入力欄・カード内部の小要素は `--line`**。迷ったら流用元の見本と同じ側にする。
- コンテナ最大幅 1180px。

## 6. 部品の使い分け (実物見本: `components/`)

- ボタン: 主要アクション1つだけ primary塗り、他はゴースト。高さ46px、ピル型、太字0.93rem。
- eyebrowラベル: セクションや資料の冒頭に置く小さなピル (primary-soft地 + primary文字 + uppercase)。ブランドの署名的パーツ。
- ステータス: 確定=primary-soft/primary、保留=茶系、完了=primary塗り+白文字。
- 統計は「数値1.9rem/800 + 下にmutedの説明」のタイル形式。
- 免責・注意書きは `components/alerts-notes.html` のノート型を使う。
- 「注目」ラベルの使い分け: カード上のバッジは「**注目の回**」、セクション見出しのeyebrowは「**今月の注目**」。
- 写真プレースホルダの地グラデは2種を使い分ける: ヒーロー・大判 = `#2f4d50→#7f9f99`、一覧内サムネ = `#35585b→#8ea9a2`。これ以外のグラデを作らない。

## 7. レイアウトの型

- ヒーロー: 左にeyebrow→h1→リード→アクション、右に実物カード。左右非対称 (0.94fr/1.06fr)。
- スライド (16:9): 余白をたっぷり(外周64px以上)。1枚1メッセージ。本文は3点まで。
- 出典・日付・回数などのメタ情報は muted色の小さめテキストで下部か右上に。

### 開催前の告知物 (スライド・カード・SNS) の型

録画済みアーカイブとは扱いが異なる。以下が公式パターン:

- 表紙・告知カードの冒頭は「第◯回 勉強会」eyebrow + **茶系テーマチップの併置**(例: 感染症)。
- 開催前なので**再生ボタン・時間バッジは付けない**。主リンクは「開催案内を見る」「参加方法を確認」。
- 受付状況チップ(登録受付中=緑/締切間近=茶/満席=danger)は、**受付状況の情報があるときだけ**付ける。情報がなければ省略してよい。
- 日時・形式(ハイブリッド等)は必須。会場名・申込方法は情報があれば表紙サブ行またはメタ行に追加する。**情報がない項目を創作しない**(「会場: 未定」等も書かない)。
- **単発の告知物に免責文言は不要**(免責は教育内容そのものを含む資料・アーカイブページ用)。
- 演者・担当は「事務局」「運営」表記が既定。**個人名は本人の同意が確認できている指示があった場合のみ**。

## 8. やってはいけないこと (総括)

1. トークン外の色・角丸・影を発明しない
2. Learning Loop マークの形・色・比率を改変しない。旧ロゴや代替アイコンを混在させない
3. 純白背景・純黒文字にしない
4. 絵文字・感嘆符・誇大コピーを使わない
5. 実在の患者・個人名を出さない (架空例も匿名表記)
6. 医療的断定・効能保証を書かない
7. 免責文言を勝手に削らない
8. Webフォント・装飾フォントを追加しない
