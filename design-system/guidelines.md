# 臨床学術ワーキンググループ — ブランドガイドライン (AI向け仕様書)

このドキュメントは Claude Design がこのブランドの成果物 (スライド・LP・ワンページャー・SNS画像・資料) を作るときの唯一の判断基準。迷ったらここに従う。実物見本は `foundations/` `components/` `templates/` のプレビューHTMLにある。**新しい見た目を発明する前に、必ず見本から一番近いものを探して流用する。**

デザイン語彙は「クリニカル・モダン」: 白ベース、シャープなインディゴ、広い余白、1pxの精密なボーダー、控えめな影。データ可視化が主役の SaaS ダッシュボード風 (契約: サイト本体 `mockups/DESIGN_BRIEF.md` / 実装 `app/globals.css`)。

## 1. ブランドの正体

- 正式名称: **臨床学術ワーキンググループ** (英語添え字: Clinical Academic Working Group)。ヘッダー等の短縮表記は「臨床学術WG」。
- 何者か: 薬剤師・医療従事者が臨床/研究/基礎レクチャー/AI活用を学び合う勉強会。月2回以上、ハイブリッド開催、録画・資料を公開アーカイブとして整理。
- 代表コピー: 「**必要な勉強会に、すぐ届く。**」
- テーマ分類 (固定語彙・固定順): 循環器 / 脳神経 / 感染症 / 基礎レクチャー / 研究・認定 / AI活用

## 2. 声とトーン

- 落ち着いた・誠実・実務的。医療専門職に向けた文体。
- 機能価値を短文で言い切る:「すぐ届く」「見返せる」「短時間でたどり着ける」。
- 見出しは体言止めか短い言い切り。感嘆符・絵文字・煽りは使わない。
- **禁止**: 誇大表現(「誰でもプロ級」「絶対」「No.1」)、診療判断の断定(「〜すれば治る」)、効能の保証。
- 症例・患者情報は必ず匿名化した架空例のみ。個人名は出さない(運営者名も資料内では「事務局」「運営」と表記)。
- 教育コンテンツには免責を添える: 「本アーカイブは個別診療の判断を代替するものではありません。」

## 3. 色

トークンの正: `tokens/tokens.css`。実物見本: `foundations/colors.html`。以下はライトテーマ (プレビュー・成果物の既定)。ダーク値は tokens.css 末尾の参考節にあり、独自に発明しない。

| 役割 | 値 | 使い方 |
|---|---|---|
| 背景 `--bg` | `#f5f7fb` | ページ・スライドの地。クールなオフホワイト |
| 面 `--surface` | `#ffffff` | カード・パネル。背景の上に 1px ボーダーで載せる |
| 沈めた面 `--surface-2` | `#eef2f8` | 入力欄・タブ地・ホバー・引用 |
| 文字 `--ink` | `#0f172a` | 見出し・本文 |
| 準文字 `--ink-2` | `#475569` | ナビ・ボタン文字・単位 |
| 補助文字 `--muted` | `#64748b` | キャプション・メタ情報・スタットラベル |
| 罫線 `--border` | `#e3e8f0` | ボーダーは常に 1px でこの色 |
| 主色 `--primary` | `#4f46e5` | 強調・主ボタン・アクティブ状態・進捗フィル。塗り面の文字は `#ffffff` |
| 主色強 `--primary-strong` | `#4338ca` | 主ボタンhover・リンク強調 |
| アクセント `--accent` | `#0369a1` | 副次的な強調。多用しない |
| 進捗トラック `--track-primary` | `#e0e7ff` | 進捗バー/リングの未達部分 |

- 配分の目安: 背景・面が9割、primary は1割弱、accent は差し色のみ。
- セマンティック: 成功/完了=`--success #15803d`、注意/保留=`--warning #b45309`、エラー/不正解=`--danger #b91c1c`。バッジ地は各色の12%ティント (`rgba(21,128,61,0.12)` 等)。
- カテゴリ6色 (`--cat-1`〜`--cat-6`): テーマ分類の固定順に割り当てるチップ/系列色。順番を入れ替えたり文字色に使ったりしない。
- **禁止**: 純黒 `#000` 文字、トークン外の色、彩度の高い装飾色、グラデーション (地色・ボタン・見出しのグラデは使わない。面はフラット+1pxボーダーが原則)。
- ロゴマークは学びの階段。primary塗りの角丸スクエアに白の階段ライン+到達点ドットで、段階を上がる学びを表す。サイト実体は `public/images/logo.svg`。形・色・比率を改変しない (SVGパスは tokens.css 末尾に記載、見本は `foundations/brand.html`)。

## 4. タイポグラフィ

フォント: `"Inter", "Noto Sans JP", "Hiragino Sans", "Yu Gothic", sans-serif` (サイト本体は next/font でセルフホスト。プレビュー・成果物では @import せずこのスタックを書くだけでよい)。実物見本: `foundations/typography.html`。

タイプスケールは6段固定: **12 / 14 / 16 / 20 / 28 / 40px** (`--fs-xs`〜`--fs-2xl`)。中間サイズを発明しない。

| 役割 | サイズ | 行間 | 字間 | 太さ |
|---|---|---|---|---|
| 大見出し (h1/表紙) | 28px (大判媒体は40px) | 1.3 | -0.01em | 700 |
| セクション見出し (h2) | 20px | 1.3 | -0.01em | 700 |
| カード見出し (h3) | 16px | 1.3 | +0.01em | 700 |
| 本文 | 14〜16px | 1.6 | 0 | 400 |
| キャプション・メタ | 12px | 1.4〜1.6 | 0 | 400〜500 |
| スタットラベル | 12px | 1.4 | **+0.06em** | 600 |
| 統計数値 | 28px | 1.25 | -0.01em | 700 + tabular-nums |

- 原則: **見出しは締める(負の字間)、ラベルは少し開く(+0.06em)**。旧デザインのような uppercase 英字 eyebrow は使わない。
- 数値 (スタット・進捗・日付・回数) はすべて `font-variant-numeric: tabular-nums`。
- 日本語見出しの改行位置は意味で切る。
- **媒体による使い分け**: 固定サイズ媒体 (スライド16:9・A4・SNS画像) は各テンプレ見本の固定pxに従う。見本と本表が食い違うときは、その媒体の見本が正。

## 5. 形・余白・影

- 角丸4段: `--radius-sm 6px` (タブ内要素) / `--radius-md 10px` (ボタン・入力欄・ナビ項目) / `--radius-lg 14px` (カード) / `--radius-xl 20px` (大型パネル・ヒーロー)。旧デザインのピル型ボタン(999px)は使わない (ピルはバッジ・チップ専用)。
- 影は2段のみ: `--shadow-1` (カード基本の極薄) / `--shadow-2` (メニュー・モーダル等の浮遊面)。濃い影・多重影は使わない。
- 面の作り方の原則: **`--surface` + 1px `--border` + `--shadow-1`**。ボーダーレスの面や影だけのカードを作らない。
- 余白: 8px基調 (8/12/16/20/24)。カードpadding 20px (広い画面で24px)、スタットタイル 16×18px。
- コンテナ最大幅 1200px・左右padding 24px (モバイル16px)。

## 6. 部品の使い分け (実物見本: `components/`)

- ボタン (高さ約38px・radius-md・14px/600): 主要アクション1つだけ **primary塗り**、並列アクションは **secondary** (surface地+border)、行内の軽い操作は **ghost**。小型は padding 5px 12px / 12px。
- バッジ・チップ (ピル型・12px): 地は `--surface-2`、文字は `--ink-2`。テーマ分類チップは左に 8px のカテゴリ色ドットを付ける (文字は ink-2 のまま)。
- ステータスバッジ: 12%ティント地 + セマンティック色文字 + 7px currentColor ドット。確定/受付中=success、保留/締切間近=warning、中止/満席=danger。
- 統計は「12px/600/+0.06em muted ラベル → 28px/700 tabular 数値 (+単位は14px ink-2) → 12px muted 補足」のタイル形式 (`components/stats.html`)。
- 進捗バーは高さ6px・角丸3px・地 `--track-primary`・フィル `--primary`。セグメント型は隣接フィル間に2pxギャップ。進捗リングは44px・ストローク4・丸端。
- タブ: `--surface-2` 地のコンテナ (radius-md・padding 4px) に、アクティブだけ `--surface` 面 + primary文字 + shadow-1。
- 空状態: 破線ボーダー (`1px dashed --border`) の中央寄せカード。
- 免責・注意書きは `components/alerts-notes.html` のノート型を使う。
- 「注目」ラベルの使い分け: カード上のバッジは「**注目の回**」、セクション見出しの添えは「**今月の注目**」。

### データ可視化 (dataviz 準拠)

- スタット数値・ラベル・凡例の文字色は必ずインク系 (`--ink`/`--muted`)。系列色を文字に使わない。
- 進捗・棒グラフは細いマーク・角丸端。積み上げ・隣接フィル間は2pxのサーフェス色ギャップ。
- 系列2つ以上は凡例必須。1系列は凡例なし (タイトルが名前を兼ねる)。2軸チャート・レインボー禁止。
- ステータス色は状態専用で系列色に流用しない。色だけで状態を伝えない (ラベル併記)。
- カテゴリ色はテーマ固定順で割り当て、フィルタや文脈で塗り替えない。

## 7. レイアウトの型

- ヘッダー: 高さ60px・sticky・`--surface` 地 + 下ボーダー。左にロゴ+「臨床学術WG」、ナビ (ホーム/アーカイブ/コース/カレンダー/ダッシュボード)、右端にテーマトグル。
- ダッシュボード型ホーム: 上段にスタットタイル4枚、その下は12カラムグリッドで情報密度高く。カード同士のガターは16〜24px。
- スライド (16:9): 余白をたっぷり (外周64px以上)。1枚1メッセージ。本文は3点まで。
- 出典・日付・回数などのメタ情報は muted色 12px で下部か右上に。

### 開催前の告知物 (スライド・カード・SNS) の型

録画済みアーカイブとは扱いが異なる。以下が公式パターン:

- 表紙・告知カードの冒頭は「第◯回 勉強会」ラベル + **テーマ分類チップ (カテゴリ色ドット付き) の併置** (例: 感染症)。
- 開催前なので**再生ボタン・時間バッジは付けない**。主リンクは「開催案内を見る」「参加方法を確認」。
- 受付状況バッジ (登録受付中=success / 締切間近=warning / 満席=danger) は、**受付状況の情報があるときだけ**付ける。情報がなければ省略してよい。
- 日時・形式(ハイブリッド等)は必須。会場名・申込方法は情報があれば表紙サブ行またはメタ行に追加する。**情報がない項目を創作しない**(「会場: 未定」等も書かない)。
- **単発の告知物に免責文言は不要**(免責は教育内容そのものを含む資料・アーカイブページ用)。
- 演者・担当は「事務局」「運営」表記が既定。**個人名は本人の同意が確認できている指示があった場合のみ**。

## 8. やってはいけないこと (総括)

1. トークン外の色・角丸・影・フォントサイズを発明しない
2. 学びの階段マークの形・色・比率を改変しない。旧ロゴ (Learning Loop・パルス波形) や代替アイコンを混在させない
3. 旧デザインの語彙 (暖色オフホワイト地・ティール・茶アクセント・ピル型ボタン・28px角丸パネル) に戻さない
4. 絵文字・感嘆符・誇大コピーを使わない
5. 実在の患者・個人名を出さない (架空例も匿名表記)
6. 医療的断定・効能保証を書かない
7. 免責文言を勝手に削らない
8. Webフォントの @import・装飾フォントを追加しない (フォントスタック指定のみ)
